# Overview

The Defra AI Security Guardrails define the **baseline security expectations** for all AI systems across Defra and its ALBs.

## What is an AI workload?

An AI workload includes:

- Model training  
- Model inference  
- Data pipelines  
- AI-enabled applications  
- Supporting infrastructure  

Examples include:

- Flood prediction models  
- NLP document classification  
- Computer vision for land use  
- Public-facing chatbots  
- AI-powered APIs  

---

## Key characteristics of AI

AI systems differ from traditional systems:

- Non-deterministic (same input ≠ same output)  
- Data-dependent (quality of input data drives behaviour)  
- Adaptive (models may evolve or drift over time)  

---

## Why this matters

These characteristics introduce risks such as:

- Prompt injection  
- Data leakage  
- Model manipulation  
- Bias and fairness issues  

---

## Core principles

AI security in Defra is based on:

- Consistency across all AI workloads  
- Controls proportionate to risk  
- Reusable guardrails, not bespoke rules  
- Platform-agnostic implementation  

---

## Who this is for

This guidance applies to:

- Programme leads  
- Project and product managers  
- Technologists (architects, engineers, data scientists)
