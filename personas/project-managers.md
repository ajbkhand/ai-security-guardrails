# Project and product managers checklist

This checklist applies to:
- Project managers  
- Product managers  
- Delivery leads  

Focus: **Embedding guardrails into delivery**

---

# ✅ Concept stage

## You must:

- [ ] Define clear problem and success metrics  
- [ ] Identify data requirements and sensitivity  
- [ ] Confirm whether AI adds value  
- [ ] Plan for DPIA if needed  
- [ ] Identify stakeholders (security, legal, architecture)  

---

# ✅ Incubate stage

## You must:

- [ ] Ensure data quality checks are completed  
- [ ] Ensure secure architecture is designed  
- [ ] Plan testing (security, bias, robustness)  
- [ ] Define user experience and human interaction  
- [ ] Ensure resources allocated for compliance activities  

## You must plan for:

- Red-teaming  
- Monitoring  
- Documentation  

---

# ✅ Pilot stage

## You must:

- [ ] Ensure DPIA is approved  
- [ ] Ensure ATRS is published (if required)  
- [ ] Deliver testing:
  - Prompt injection  
  - Bias and fairness  
  - Misuse scenarios  

- [ ] Ensure:
  - User disclosures exist  
  - Human fallback exists  
  - Runbooks are defined  

---

# ✅ Scale stage

## You must:

- [ ] Ensure monitoring dashboards exist  
- [ ] Ensure incident response processes are active  
- [ ] Ensure regular evaluation cycles  
- [ ] Ensure compliance artefacts are maintained  

## You must manage:

- Cost (FinOps)  
- Sustainability (GreenOps)  
- Operational performance  

---

# ✅ Summary

You are responsible for ensuring that:

- Guardrails are built into delivery (not added later)  
- Security and governance are funded and prioritised  
- Teams meet required standards before release
